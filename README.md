# 실습 아카이브 (si-archive)

스마트 인터랙션 디자인 수업에서 만든 실습을 모아 두는 내 웹사이트입니다.
카탈로그 97개마다 **따라 하기 1개 + 내 응용 1개**, 모두 **194개**를 이곳에 올립니다.
TA와 교수님은 이 사이트로 실습을 확인하고, 수강생끼리 서로의 작업을 볼 수 있습니다.

- 내 사이트 주소: `https://<내 GitHub 아이디>.github.io/si-archive/`
- **만들기도 올리기도 Claude 데스크톱 앱에서 말로 합니다.** 코드와 터미널은 쓰지 않습니다.
- 이 사이트는 **인터넷에 공개**됩니다(무료 GitHub는 공개 저장소에서만 사이트를 만들 수 있어요). 전화번호·학번·주소 같은 개인 정보는 넣지 마세요. 이름 대신 별명을 써도 됩니다.

### 도구의 역할
| | 하는 일 | 비유 |
|---|---|---|
| **Claude 데스크톱 앱 · Code 탭** | 실습 파일을 만들고, "올려 줘"라고 하면 저장·올리기까지 합니다 | 작업대 + 택배 |
| **GitHub** | 내 파일과 "언제 무엇을 올렸는지" 기록을 보관합니다 | 창고 |
| **GitHub Pages** | 창고의 파일을 누구나 보는 내 사이트로 보여 줍니다 | 전시장 |

### 처음 나오는 말 풀이
- **저장소(repository)**: GitHub 창고 안에 있는 내 프로젝트 폴더 하나입니다. 이 수업에서는 `si-archive` 하나입니다.
- 같은 파일을 두 주소로 볼 수 있습니다. **`github.com/…`(창고)** 에서 html 파일을 누르면 **항상 코드**가 나옵니다(정상). 움직이는 화면은 **`…github.io/…`(전시장)** 에서 봅니다.
  - 예: 창고 `github.com/내아이디/si-archive/blob/main/works/24/mine/index.html` → 전시장 `내아이디.github.io/si-archive/works/24/mine/`
- **저장(Commit) · 올리기(Push)**: Claude가 대신 하는 일입니다. Claude의 안내에 이 말이 나오면 "사진 찍듯 저장" · "서버로 보내기 = 제출"로 읽으면 됩니다.
- **공개(Public)**: 주소를 아는 누구나 볼 수 있다는 뜻입니다.
- **충돌(conflict)**: 같은 곳을 두 군데에서 따로 고쳐서 자동으로 합칠 수 없다는 뜻입니다. Claude가 이 말을 하면 아무것도 하지 말고 TA를 부르세요.
- **noreply 이메일**: 진짜 이메일 대신 쓰는 주소입니다. 올린 기록에 내 진짜 이메일이 남지 않게 해 줍니다. 세팅 때 Claude가 맞춰 둡니다.

> 철칙 두 개: **① GitHub 웹사이트에서 파일을 직접 고치지 않기** (내 컴퓨터와 서버가 어긋납니다. 고칠 것은 Claude에게) · **② 공개되면 안 되는 정보 넣지 않기** (지워도 기록에 남습니다)

## 처음 한 번 — 세팅

> 처음 한 번만 하면 됩니다. 메일 인증을 기다리는 시간과 공개 주소가 켜지는 시간(보통 수십 초, 늦으면 10분)이 있어요. 막히면 혼자 오래 붙잡지 말고 TA를 부르세요.

### 1. GitHub 가입 (직접)
1. github.com → **Sign up**. 가입 화면은 자주 바뀌니 칸 이름(Email · Password · Username)을 보고 채웁니다.
   - **Username(아이디)는 사이트 주소가 됩니다.** 영문 소문자로 짧게 정하세요.
   - 비밀번호는 직접 입력하고 Claude·TA·친구에게 보내지 않습니다.
2. 가입한 메일함에 온 GitHub 메일의 안내대로 **메일 인증**을 끝냅니다. 인증하지 않으면 저장소를 만들 수 없습니다.
3. GitHub 오른쪽 위 프로필 사진 → **Settings** → 왼쪽 **Emails** → **Keep my email addresses private** 와 **Block command line pushes that expose my email** 을 둘 다 켭니다.

### 2. Claude 데스크톱 앱 준비 (직접)
1. Claude 데스크톱 앱을 최신 버전으로 업데이트하고 로그인합니다(Pro 이상). 왼쪽 위에 **Code** 탭이 보이면 OK.
   - 윈도우에서 Code 탭이 "Git을 설치하라"고 하면 git-scm.com 에서 Git을 설치한 뒤 앱을 다시 켭니다.
2. Code 탭에서 작업 폴더를 **문서**(Documents) 폴더로 고릅니다.

### 3. Claude에게 세팅 맡기기
아래 문장을 그대로 붙여 넣고 `○○○` 만 바꿉니다.
```
https://raw.githubusercontent.com/KIKI0715/si-setup/main/SETUP.md 를 원문 그대로 받아 읽고, 그 순서대로 내 실습 사이트를 세팅해 줘. 공개용 이름은 ○○○야.
```
Claude가 도구 설치 → 내 저장소 만들기 → 공개 주소 켜기 → 첫 화면에 이름 넣기 → 올리기까지 순서대로 합니다. 그동안 내가 할 일은 셋입니다.
- Claude가 명령을 실행하려 할 때 앱에 뜨는 확인 → **허용**
- 맥에서 "명령어 개발자 도구를 설치하겠습니까?" 창이 뜨면 → **설치** (수 분 걸림)
- Claude가 보여 주는 **코드(예: ABCD-1234)** 를 자동으로 열린 GitHub 페이지에 넣고 → **승인(Authorize)**. GitHub 로그인이 필요하면 그 페이지에서 직접 합니다.

끝나면 Claude가 **내 사이트 주소**를 알려 주고 브라우저로 열어 줍니다. **97행 × 2열(194칸) 격자**가 보이면 성공입니다. 이 주소를 TA에게 제출합니다(제출 방법은 수업에서 TA가 알려 줍니다).

## 매번 하는 일

Claude 앱 Code 탭에서 폴더를 **문서 › si-archive** 로 고르고 시작합니다. 시작할 때 Claude가 서버의 최신 상태를 먼저 받아 옵니다.

### ① Claude에게 만들기
카탈로그(갤러리)에서 그 번호의 **한 줄** 또는 **5칸 명세**를 복사해 붙입니다. 5칸 명세는 이렇게 읽습니다: **[오브젝트]** 움직이는 대상(어느 물건이 움직이나) · **[트리거]** 언제 시작하나(무엇을 하면 시작되나) · **[반응]** 무엇이 어떻게 변하나 · **[조건]** 어떤 경우에만 그러나 · **[변수]** 화면이 기억해 두는 값.
```
24번 따라 하기 추가해 줘. 넣을 문장: (복사한 문장)
```
내 응용은 원본에서 무엇을 바꿨는지 함께 말합니다.
```
24번 내 응용 만들어 줘. 넣을 문장: (내가 쓴 문장)
이름: 재생목록 시트 / 바꾼 점: 바텀 시트를 음악 재생목록으로, 높이 3단계에 뒤 화면 어두워짐 추가
```

### ② 내 컴퓨터에서 확인
Finder(윈도우는 파일 탐색기)에서 `si-archive/works/24/mine/index.html` 을 더블클릭해 직접 조작해 보고, `si-archive/index.html` 에서 24번 칸이 채워졌는지도 봅니다. 여기까지는 내 컴퓨터 안에서만 바뀐 것이라 아직 아무도 못 봅니다.

### ③ 올리기
```
올려 줘
```
- Claude가 바뀐 파일을 알아볼 말로 보여 주고, **실습마다 따로 저장**한 뒤 서버로 올립니다. **이것으로 제출 끝.**
- 모르는 파일, 개인 파일, 아주 큰 파일이 보이면 "그건 빼고 올려 줘"라고 하면 됩니다.
- Claude가 그 실습의 공개 주소를 알려 줍니다. 반영은 보통 수십 초, 늦으면 10분.

## 지켜 주세요
- **한 번에 하나만.** 여러 개를 한꺼번에 시키면 어디서 틀렸는지 찾기 어렵습니다.
- **고칠 때는 값 하나만.** "더 멋지게"보다 "튕기는 높이만 300에서 200으로"가 정확합니다.
- **기술 이름 대신 보이는 것과 숫자로 말합니다.** 카탈로그 부록 "기술 이름 대신 쓰는 말" 참고.
- 영상·이미지는 **파일 하나 20MB 이하** (수업 기준입니다. GitHub는 약 50MB부터 경고, 약 100MB부터 거부). ProtoPie 화면 녹화는 영상(mp4) 파일로 줄여서 넣습니다. `.zip`·`.psd`·`.ai`·`.pie`·`.fig` 파일은 실수로 올라가지 않게 막아 두었으니(`.gitignore`) 넣지 마세요.
- 첫 화면(`index.html`)과 `data/works.js` 는 Claude가 관리합니다. 직접 고치지 않습니다.
- Claude가 명령을 실행하려 할 때 **무슨 일인지 모르겠거나 "지운다·강제로" 같은 말이 보이면 허용하지 말고** TA에게 물어봅니다.

## 막혔을 때

| 증상 | 해 볼 것 |
|---|---|
| 공개 주소가 404 | 반영에 최대 10분. 10분 뒤 강력 새로고침. 그래도 안 되면 Claude에게 "공개 주소 상태 확인해 줘" → 결과를 TA에게 |
| GitHub에서 html 파일을 눌렀더니 코드만 보임 | 정상입니다. 거기는 창고(`github.com`)라 항상 코드로 보여 줍니다. 움직이는 화면은 내 사이트 주소(`내아이디.github.io/si-archive/`)에서 해당 칸을 누르거나, 올리기 전이면 내 컴퓨터에서 파일을 더블클릭해 봅니다 |
| 사이트에 옛 화면이 보임 | 브라우저 강력 새로고침 (맥 ⌘⇧R · 윈도우 Ctrl+Shift+R) |
| 로그인 코드 페이지를 닫았거나 승인을 못 함 | Claude에게 "GitHub 로그인 다시 해 줘" |
| Claude가 "충돌(conflict)"이라고 함 | 아무것도 하지 말고 TA를 부릅니다. Claude가 원래대로 돌려 둡니다 |
| 다른 실습이 망가짐 | "방금 올린 거 취소해 줘" (그 기록에 실습이 여러 개 묶였다면 혼자 하지 말고 TA) |
| 메일 인증 안내가 계속 뜸 | 가입한 메일함의 GitHub 메일 안내대로 인증을 끝냅니다 |
